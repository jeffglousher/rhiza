`N` is the writer version named above. `N-1` is deliberately unsupported for
every listed durable layout. A writer-format change requires a clean install or
an operator-reset durable root; this release provides no in-place or offline
migration path, and mixed binaries must not write that change.
Checkpoint and archive snapshots have distinct namespaces but are profile-owned
payloads: SQL is `QSNP`, graph is `RHGS`, and KV is `RHKS`. The archive key's
last component is the executor fingerprint, not a content hash. A profile must
fail closed for another profile's payload. No profile migrator or power-loss
fixture is claimed by this inventory.
